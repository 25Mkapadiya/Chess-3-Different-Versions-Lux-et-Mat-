Lux et Mat

by Allen Huang, Milind Kapadiya, and Mason Mifflin

Download the original Lux et Mat Java desktop game. The interface, artwork, game modes, and gameplay remain unchanged from the original project.

Download for Mac Download for Windows

How to run it on Mac

  1. Download and unzip the Mac file.
  2. Keep Lux-et-Mat.jar and the resources folder together.
  3. Open Terminal and run java -version. Java 8 or newer is required.
  4. Type cd , drag the unzipped folder into Terminal, and press Return.
  5. Run java -jar Lux-et-Mat.jar.

How to run it on Windows

  1. Download and unzip the Windows file.
  2. Keep all files in the unzipped folder together.
  3. Double-click Run-Lux-et-Mat.bat.
  4. If Windows asks for permission, choose to run the file.
  5. Java 8 or newer is required.

GitHub Pages hosts the downloads. The Java Swing game itself runs locally on your laptop, not inside the browser.
